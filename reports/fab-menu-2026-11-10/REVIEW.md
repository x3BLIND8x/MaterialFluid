## FAB Menu reference additions, 2026-11-10

Reviewed Floor Material's FAB Menu factory/config/constants/types, reveal-order logic, React and Web Component adapters, styles and behavior/style tests. Source URLs and reviewed SHA-256 hashes are recorded in source.json; the retained Floor Material MIT notice applies. Direct access to the reference page returned a cache miss, so the authoritative source was used.

FABMenu now implements both source presentations: the expressive list below 600px and the shared baseline Menu above, with explicit overrides. Auto presentation locks while open and resolves the latest width on close. The labelled action list reveals nearest-first, closes top-first, and transforms the trigger into a round 56px close action. Logical bottom placement mirrors RTL with 16px container insets, or 24px from 1200px. The six shared FAB size/color foundations remain owner primitives: three role/container pairs, default/medium/large sizes and compatible legacy sizes. Existing label/MenuItem arrays and callbacks are preserved, while typed source-style events, controlled state, imperative handles, declarations and custom menu adapters are additive.

All spatial motion uses the owner finite popup/press/resize system. CSS owns simple color/opacity fades and measured action-width reveal; a private composition radius value combines trigger shape morphing with shared press/ripple feedback without adding a public tuning prop. Content stays at its resting size during pressing. Elevation, Square and public motion/ripple/icon-size controls remain excluded. The baseline reuses the existing shared Menu module instead of adding a second menu implementation or introducing another asynchronous loader.

The optional mf-fab-menu/mf-fab-menu-item adapter reflects open state before dispatching events. Setting/removing the open property/attribute applies quietly, while show/hide/toggle and user interactions dispatch events. Declarative action mutations, custom adapters, disabled state, reconnection and lifecycle cleanup are supported. Stable declarative snapshots prevent a label update from rebuilding an app-owned menu. Configuration uses only Example Presets, Appearance, Content and Behavior, including full optional icon selection. Documentation contains API details and synchronized React/Web Component recipes. The visible catalogue remains 45 entries.
