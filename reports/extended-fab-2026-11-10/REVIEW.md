## Extended FAB reference additions, 2026-11-10

Reviewed the reference factory, config, constants, public API/types, React/Web adapters, scroll handling, source styles and naming/event/size fixtures. The reference page returned a cache miss, so authoritative Floor Material source was inspected. Reviewed source URLs, SHA-256 hashes and tree identity are in source.json; the retained MIT notice applies.

ExtendedFAB is implemented at the shared library boundary using Button and the existing paired FAB color roles, owner fonts/weights, 24/29px FAB radii, finite geometry/press curves, ordinary whole-surface color fades and live ripple sizing. It has small/medium/large heights of 56/80/96px, icons 24/28/32px, start/end icon placement, content width or full parent width, manual/controlled/scroll collapse, native forms, logical/physical placement precedence and a native-compatible ref with content, value, appearance, state, event and lifecycle methods. Source lower/raise/elevation, Square, independent icon sizing and public animation controls remain excluded.

Actual width semantics were inspected rather than inferred from contradictory source comments: fixed is intrinsic content width; fluid fills the container. Fluid mode observes parent content-width changes and retargets shared Button geometry without repeated measurement on unrelated renders. Compact mode matches its selected height and hides text visually while retaining its accessible name. Text names the button unless an explicit ariaLabel is supplied. Mouse/focus/touch subscription payloads retain their native event types via a backwards-compatible generic FABEvent.

Extended FAB is selectable in the existing FAB page's Appearance group. The visible catalogue stays at 45 entries. Configuration contains Example Presets, Appearance, Content and Behavior with the full optional icon picker; Documentation contains the selected React/Web recipe and additive API details. The optional mf-extended-fab adapter projects original native label nodes, preserving markup, node identity and native listeners, and supports reflection, forms, lifecycle and reconnect. Explicit collapse/expand calls reach DOM/API listeners once per call, including repeated calls; property-only state updates apply quietly. The source scroll threshold remains 10px, with upward/top-of-page expansion and frame/listener cleanup.
