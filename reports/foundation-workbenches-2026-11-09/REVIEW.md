## Delay diagnosis

An unchanged Button repeatedly cloned itself for color measurement on every render. Geometry also depended on freshly created React children rather than actual DOM changes. A single size update created 102 clones, a shape selection 114, and typography 61. The shared hooks now react to relevant style/state changes and actual content mutations. Regression counts are 3, 4 and 0 respectively, with no SVG geometry sampling during built-in selection.

In local production-preview measurements before/after, first visible Button size change was about 89/25 ms, Shape 170/21 ms and typography 47/15 ms. These are observations on this machine, not timing guarantees. Concurrent builds/tests produced scheduling outliers, so regression tests assert bounded measurement work and visible animation frames rather than a fragile wall-clock threshold. Motion durations and finite profiles remain intact.
